# Cambridge 查词

macOS 菜单栏词典工具，查询剑桥词典英汉繁体释义，原生 AppKit UI，无 Electron / WebView。

---

## 功能

- **划词查询** — 选中任意应用中的单词，按全局快捷键自动复制并查询
- **手动查询** — 主界面搜索框输入单词回车查询
- **英式 / 美式发音** — 点击 🔊 UK / 🔊 US 按钮播放真人发音
- **历史记录** — 自动记录查询记录，侧边栏快速回顾
- **收藏夹** — 收藏单词，支持导出为 Excel
- **中文释义** — 英文定义 + 繁体中文翻译 + 例句（斜体）
- **词性分组** — 每个词性独立分组，黄色分隔线区分
- **离线缓存** — 查过的单词本地缓存 7 天，无需重复联网

## 安装 & 构建

### 依赖

```bash
pip install pyobjc-core pyobjc-framework-Cocoa pyobjc-framework-Quartz \
            requests beautifulsoup4 lxml openpyxl py2app
```

> 需要 Python 3.9+，**不支持 Anaconda / miniforge**（PyObjC 兼容性问题）。

### 开发模式（秒级构建）

```bash
bash build.sh --dev
```

生成 `dist/Cambridge.app`，通过符号链接引用源码，修改后重启 App 即生效。

### 正式打包

```bash
bash build.sh
```

生成可分发的独立 `.app`。

## 使用

1. 启动 `Cambridge.app`，菜单栏出现 **C** 图标
2. **左键点击** C 图标呼出主界面
3. **右键点击** 打开菜单（偏好设置 / 退出）

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `⌘⇧C` | 划词查询（选中文字后按） |
| `⌘⌥Space` | 呼出 / 隐藏主界面 |

> 两个快捷键均可在偏好设置中自定义，支持冲突检测。

### 首次使用

1. 系统会弹出**辅助功能权限**请求 → 点击「打开系统设置」→ 勾选本应用
2. 重启 App，全局快捷键即可生效

## 分发给其他 Mac

### 打开方式（绕过 Gatekeeper）

由于 App 未经 Apple 公证，macOS 默认会拦截。首次打开方式：

1. **不要双击**，改为「**右键单击** → 打开」
2. 弹出警告窗口后点击「打开」
3. 此后双击可正常启动

或者在终端执行：

```bash
xattr -cr /path/to/HotDict.app
```

之后双击即可正常打开。

### 权限设置

首次使用需授予两项权限：

| 权限 | 触发时机 | 设置方式 |
|------|---------|---------|
| 辅助功能 | 首次按快捷键时自动弹窗 | 弹窗中直接授权即可 |
| 输入监控 | 不弹窗 | 系统设置 → 隐私与安全性 → 输入监控 → 手动开启 |

> **注意**：只要辅助功能已授权，输入监控通常不需要手动开启。仅在快捷键仍不响应时才需要。

## 偏好设置

右键菜单栏 C 图标 → 偏好设置

| 设置项 | 说明 |
|--------|------|
| 全局查词快捷键 | 划词查询触发键，录制方式设置 |
| 呼出主界面快捷键 | 呼出 / 隐藏主窗口触发键 |
| 查询接口地址 | 自定义词典 URL，留空恢复默认 |
| 侧边栏默认状态 | 启动时是否自动展开历史/收藏侧边栏 |

## 数据存储

所有数据存储在 `~/.cambridge_tool/`：

| 文件 | 内容 |
|------|------|
| `history.json` | 查询历史，最多 200 条 |
| `favorites.json` | 收藏单词及完整词条数据 |
| `cache.json` | 词条缓存，7 天 TTL |
| `settings.json` | 偏好设置 |
| `app.pid` | 单实例守护 PID |
